# Usage

## Dependencies (download and put to current directory)

NeoVIM App Image
```
https://github.com/neovim/neovim/releases/latest/download/nvim-linux-x86_64.appimage
```

FastGithub release directory(unzip, rename publish directory to fastgithub directory and put to current directory)
```
https://github.com/creazyboyone/FastGithub/releases/download/v2.1.5/fastgithub-linux-x64-ok.tar.gz
```
